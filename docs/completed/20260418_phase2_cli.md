# 2026-04-18 Phase 2 CLI

`cmd/cli/main.mbt` を更新し、CLI の Phase 2 要件を実装。

## 変更内容

- `list-collections` サブコマンドを追加
  - 対応フラグ: `--parent`, `--page-size`, `--page-token`
  - 出力: `{ "collectionIds": [...], "nextPageToken": "..."? }`
- `aggregate` サブコマンドを追加
  - 対応フラグ: `--count [alias]`, `--sum field[:alias]`, `--avg field[:alias]`
  - `--where` / `--op`、`--explain` / `--analyze` を追加
  - alias 省略時は `count_1`, `sum_<field>`, `avg_<field>` を自動生成
  - 通常時は `[{ "alias_": "...", "value": ... }]` を出力
  - explain 時は `{ "results": [...], "metrics": { "planSummary": ..., "executionStats": ... } }`
- 既存 `query` サブコマンドを拡張
  - 追加フラグ: `--order field[:asc|desc]` (複数可), `--offset N`, `--and FIELD=VALUE:OP` (複数可), `--explain`, `--analyze`
  - 既存 `--where` / `--op` / `--limit` との互換を維持
  - explain 時は `{ "documents": [...], "metrics": {...} }` 形式
- `USAGE` を全サブコマンド/フラグに合わせて更新
